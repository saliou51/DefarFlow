# DefarFlow - Product Brief

## Summary

DefarFlow helps an organization manage maintenance requests from report to
closure. The product replaces scattered communication with a shared request
workflow for employees, managers, and technicians.

## Current Release

The current target is `v0.1`, a pilot-ready web application.

This version is not a full facility management suite. It focuses on the minimum
workflow needed to validate whether teams will use the product:

1. report an issue
2. assign it
3. process the intervention
4. close the request
5. keep the history

## Users

- Employee: reports issues and follows progress.
- Manager: prioritizes, assigns, and closes work.
- Technician: handles assigned interventions.

## Product Principles

- Keep the request workflow fast.
- Make status and ownership visible.
- Preserve history automatically.
- Prefer a reliable web experience before adding native mobile apps.
- Validate with real usage before expanding the feature set.

## Non-Goals

The following are deliberately excluded from the first release:

- billing
- accounting
- team chat
- complex AI features
- advanced inventory
- multi-site enterprise administration
